Building software is not the same anymore. I vividly remember learning Python and all the nitty gritty of setting up a backend server, going to code forums to find answers. I couldn't even dream of creating frontend applications but it was fun times.

Then came the copy-pasting code era. I remember I created my first frontend application when ChatGPT came out. It was basically a crawler with UI for all pets available for adoption in Toronto area. Even with the assist, I felt a sense of accomplishment at the end of the day.

Today, however, the story is different. What started as agent-supported coding is now completely autonomous. I don't look at the code anymore. I still know what pieces sit where, but the code itself, the LLMs write it better than I could ever.

Which begs the question, what's next? After thinking about this for a while, I came to the following three conclusions 
1. I either want to work on the fundamentals that enables these LLMs to write better code or 
2. I want to work on tools that enables millions to use the LLMs and build better software or
3. Infra that allows humans and LLMs to deliver at scale

But before diving into product and people building around those two spectrums, I need to understand what I am good at and what leverage I can bring to the table.
